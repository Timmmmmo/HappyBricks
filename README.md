# 快乐消除 Happy Bricks

一款温馨风格的弹球消除砖块游戏，参考"我的快乐瀑布"设计。

## 玩法

- 👆 **滑动瞄准** — 向上滑动确定发射方向
- 🚀 **松开发射** — 弹球撞击砖块
- 🔢 **数字=次数** — 砖块上的数字表示需要击中的次数

## 特色

- 👨‍👦 **父子角色** — 温馨家庭主题
- 🎨 **清新配色** — 天蓝色渐变背景
- ✨ **特殊砖块** — 金币砖块/炸弹砖块/多球砖块
- 🎯 **关卡系统** — 5个预设关卡+无限模式

## 特殊砖块

| 类型 | 图标 | 效果 |
|-----|-----|-----|
| 金币 | ⭐ | 消除获得50分 |
| 炸弹 | 💣 | 爆炸摧毁周围砖块 |
| 多球 | ✨ | 分裂出额外的球 |

## 技术栈

- 纯HTML/CSS/JavaScript
- Canvas渲染
- 触控友好
- 单文件架构（~21KB）
